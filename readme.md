# 🚀 AC Price Prediction

A Machine Learning project that predicts Air Conditioner (AC) prices based on key specifications and features using Multiple Linear Regression.

---

## 📌 Project Overview

This project builds a regression model to estimate the price of an Air Conditioner based on essential factors such as capacity (tonnage), energy star rating, brand, and type.

## 🧮 Algorithm

- **Multiple Linear Regression**

## 📊 Input Features

- **Capacity (in Tons):** e.g., 1.0, 1.5, 2.0 Ton
- **Energy Rating:** Star rating (1 Star to 5 Star)
- **Inverter Tech:** Inverter vs. Non-Inverter
- **Brand / Features:** Key specs impacting market price

## 🎯 Target Variable

- **Price (in ₹ / INR)**

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib / Seaborn**
- **Scikit-learn**
- **Google Colab / Jupyter Notebook**

---

## 🔄 Project Workflow

1. **Dataset Inspection & Loading:** Load and inspect the dataset.
2. **Data Cleaning:** Check for missing values, duplicates, and data formatting.
3. **Exploratory Data Analysis (EDA):** Visualize relationships between capacity, ratings, and price.
4. **Data Splitting:** Split data into training and testing sets.
5. **Model Training:** Train the Multiple Linear Regression model on training data.
6. **Prediction & Evaluation:** Predict prices on test data and evaluate model performance.

---

## 📈 Evaluation Metrics

The model performance is evaluated using standard regression metrics:
- **Mean Absolute Error (MAE)**
- **Mean Squared Error (MSE)**
- **Root Mean Squared Error (RMSE)**
- **R² Score**

---

## 💻 How to Run

1. Open the `.ipynb` notebook in **Google Colab** or **Jupyter Notebook**.
2. Run all cells in sequential order.
